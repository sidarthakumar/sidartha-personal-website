A lightweight personal WordPress portfolio. Install the Sidartha Portfolio
companion plugin for editable projects, skills, milestones and public profile
settings. No page builder, external fonts, trackers, Node.js, or application
server is required in production.

INSTALLATION
Upload this ZIP in Appearance > Themes > Add New > Upload Theme. Activate it
after a backup and on staging first. Install/activate Sidartha Portfolio, then
use Settings > Portfolio profile to create starter drafts and edit public details.
Review/publish the selected pages and articles, keep Privacy as a draft until
owner review, configure Settings > Reading, and assign a Primary navigation menu.

Page templates: About, Skills & Technologies, Projects, Learning Journey, Contact.
Homepage: automatic front-page template, with introduction/photo/footer in
Settings > Portfolio profile and the editorial note in the Home page editor.
Articles: normal WordPress Posts; reading time estimates use 200 words/minute.

SECURITY / PRIVACY
Version 1.0.2 prefers the published page selected in Settings > Privacy for the
footer Privacy Policy link. A published starter policy is a legacy fallback;
drafts are never linked. No privacy settings or content are migrated.
Only use an intentionally public contact email, distinct from the WordPress
administrator email. No contact form or email-delivery service is included.
The contact link opens the visitor's email application. No delivery claim is made.
Do not enable analytics, external embeds or trackers without owner review.
The plugin and theme do not remove content on deactivation.

ASSETS
CSS artwork and icons are original project source. No stock photos, third-party
fonts, client logos, fabricated portraits, or bundled JavaScript libraries.
The optional theme screenshot shows the local development website, not a client.

See repository docs/website-installation.md, docs/content-editing.md,
